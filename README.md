# 🌐 Portafolio Personal · Santiago Uribe Duarte

Este proyecto es un portafolio web diseñado para presentar mi información personal, habilidades, educación, proyectos y formas de contacto de una manera clara y ordenada.  
El sitio está construido **exclusivamente con HTML y CSS nativo**, sin frameworks ni librerías externas, para asegurar un aprendizaje sólido y un control total del diseño.

---

## ✅ Estructura del Proyecto

El portafolio está compuesto por **dos archivos principales**:

### **1. `index.html`**
Contiene toda la estructura del sitio usando etiquetas semánticas como:

- `<aside>` para la barra lateral.
- `<section>` para separar contenido.
- `<article>` para describir información específica.
- `<ul>` y `<li>` para listas limpias.
- `<blockquote>` para la frase motivacional.
  
El HTML está escrito con clases personalizadas y **no incluye ningún estilo inline**.

---

### **2. `style.css`**
Incluye todo el diseño visual del portafolio:

- Layout principal con **CSS Grid**.
- Sidebar fija con fondo oscuro.
- Paleta de colores simple y profesional.
- Tarjetas con bordes suaves y transparencia.
- Secciones responsivas para pantallas pequeñas.
- Estilos específicos basados en **tus clases**, tal como aparecen en tu HTML.

El CSS es 100% nativo:  
No usa Bootstrap, Tailwind, ni frameworks.
